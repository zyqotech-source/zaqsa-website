# Photos

Drop real photos in this folder and the site picks them up automatically — no code changes.
Name each file after its slot (WebP preferred, max 1600px wide, compressed).

| File name (.webp .jpg .jpeg .png .avif) | Where it appears |
| --- | --- |
| `hero-team`, `hero-collab`, `hero-client` | The three floating cards beside the home hero sphere |
| `service-consulting`, `service-technology`, `service-business`, `service-civic` | Hover photo beside each service group on Home |
| `process-1` … `process-4` | Photo beside each step of the process on Home |
| `stack-team` | Wide photo between the technology marquee rows |
| `bg-team` | Faint blurred team photo behind the big text |
| `stat-1` … `stat-4` | Small round photos above the stats |
| `cta-group` | Group photo in the closing call to action |
| `contact-team` | Team photo beside the contact form |
| `team-founder` | Founder card on the About page |

Any slot without a file shows a soft blue placeholder labelled "Add photo here"
(a few large slots show an existing site image until a real photo is added).
